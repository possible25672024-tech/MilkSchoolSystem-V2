# MilkSchoolSystem V2

## Overview

MilkSchoolSystem V2 is a configurable school milk management platform.

Instead of developing a system for only one school, V2 is designed to support any school by changing only:

- School Name
- School Logo
- Firebase Configuration

No source code modification is required.

---

## Main Features

- Stock Management
- Classroom Distribution
- Teacher System
- Reports
- Backup / Restore
- Firebase Sync
- Multi School Ready
- Install Wizard
